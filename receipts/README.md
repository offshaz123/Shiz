# Receipts

Printable receipts for completed jobs. These are business paperwork, not part
of the website — `receipts/` sits outside `public/` and `src/`, so Next never
serves it and nothing here is reachable from executiveontop.com.

Open a file in a browser and use **Print receipt** to print it or save it as a
PDF.

## Conventions

- One file per receipt, named `receipt-<REG>.html`.
- Receipt numbers run in sequence. The highest number used so far is the last
  one issued; the next receipt takes the number after it.
- Customer name, payment method and who took the money are left as blank ruled
  lines to be filled in by hand, unless they were known when the receipt was
  made.
- **VAT:** the footer states that prices are not subject to VAT, which is
  correct only while the business is below the registration threshold and not
  VAT registered. If that changes, every new receipt must show the VAT number
  and the VAT split out, and this line must be removed.
